How it works

It runs before the prompt leaves the machine.

  1. 1The employee presses Enter.claude code · codex
  2. 2The tool's own hook fires, on their machine, before anything is sent.UserPromptSubmit
  3. 3Warden judges the prompt against the ratified rules.on-device
  4. 4Allowed, it continues. Blocked, the model never receives it.allow · block · escalate

A Claude Max or ChatGPT Plus session authenticates over OAuth against a fixed endpoint. There is no base URL to redirect. The hook does not care — it runs first.

UserPromptSubmit · integrations/warden-hook.mjs

Where everything runs

The record of a decision does not contain the prompt.

Every model runs on the machine, through QVAC. The audit log is append-only and hash-chained, and it stores the hash of a prompt, not the prompt — altering a past decision breaks every hash after it.
