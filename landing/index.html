Nothing checks what goes out.

Someone pastes a customer contract into Claude to have it summarised. Nobody looks at it on the way out, and nothing says it went.

Both Claude Code and Codex leave a place for that check to run, and ship with it empty.

Write a rule. It stops the request.
You see that it did.

What ran, and where
  • Qwen3-1.7B-Q4_0writes the rule, judges the prompt
  • embeddinggemma-300M-Q8_0picks which rules to judge against
  • latin_g2reads attachments — never measured
  • Qwen3-0.6B-Q4_0second injection pass — ships off, unmeasured

All of it on their machine, before the prompt is sent — which is why it works on a Max or Plus plan, where there is no base URL to redirect. Verified so far: the hook refusing a prompt in a terminal, and nothing beyond that.
