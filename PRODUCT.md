# Product

<!-- impeccable:product-schema 1 -->

## Platform
web

## Users
Team leaders, founders, operations leads and product managers responsible for employees using AI tools. Confirmed in the launch-video session.

## Product Purpose
Warden evaluates connected AI requests against administrator-defined rules. Managers describe what to protect, review generated drafts and activate rules. Policies can block requests, hold them for review or allow them to proceed.

## Operating Context
Employees keep using connected Claude Code, Codex, OpenCode and compatible tools. The landing is static HTML/CSS/ES modules, deployed from landing via the existing Vercel configuration.

## Capabilities and Constraints
Policy checks run locally; allowed requests can continue to configured providers. Rule drafting may use a configured compiler. Protection requires the appropriate tool connection. Audit is tamper-evident; masked prompt retention is separately configurable. Budget examples concern reported usage and holding subsequent requests.

## Brand Commitments
The user wants fewer words and components, black and white, and the existing official Warden logo as the central visual asset. Plaude is a supplied reference for material and effect quality. Preserve the official shield geometry, wordmark, self-hosted Manrope and useful product demonstrations. The current homepage proposal uses a centered black hero, one example on white and a compact black download close. The full policy/decision/usage story remains on how-it-works.html. The user rejected the earlier two-column hero as too text-heavy; the user authorized shipping the new version to main, then requested sharper 3D logo rendering. Preserve the existing app color system, which the user praised; this landing work does not redesign the app. The existing approved launch film stays available until a replacement is produced. Say Codex, without CLI, in customer-facing copy. Visual and video direction lives in DESIGN.md and docs/design/.

## Evidence on Hand
landing contains current copy and installer targets. videos/warden-launch contains approved video, official vectors, 3D shield and authored fictional product examples. Do not invent testimonials, customers, benchmarks or installer URLs.

## Product Principles
Make the manager's control understandable. Show the policy workflow. Keep human activation distinct from drafts. Make the free/open-source download easy to find.
